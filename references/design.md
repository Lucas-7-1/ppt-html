# 编辑与艺术指导

## 让信息变少，让意义更清楚

把材料拆成主张、证据、口径、背景。画面主要承载前三者；备注承载大部分背景。一个短案例通常不需要“封面—范围—结果—状态—建议”五件套。

虚构示例：材料仅有“调研10款、其中4款试用、成交约为标价70%、合同完成履约”时，先试一张完整案例页。价格结果作为主视觉；调研/POC范围作为支持信息；履约状态作为交付结果。只有观众需要单独讨论验证方法或价格口径时才拆页。没有提供的方法、胜出原因和收益不要编造，通用建议不要自动追加。

同一个信息跨页出现时，后页必须增加有用的解释或证据。封面说70%，正文又说70%，状态页又复述完成履约，不是叙事推进。精简依靠信息合并与表达转换，不能只靠删文字、留大片无意义空白。

### 改写先改变表达

| 普通写法/做法 | 编辑方向 |
| --- | --- |
| 标题“价格结果”，正文重复说明结果 | 直接让有口径的结果承担标题或主视觉 |
| “通过多方协同、深化合作、实现价值提升” | 写出实际做了什么、拿到什么；无证据就删除 |
| 每个数字分别做一页 | 把属于同一主张的数字放在同一视觉关系里 |
| 图表、标题、注释三遍说同一句话 | 标题讲结论，图形给证据，注释只保留口径 |
| 页脚堆栏目名、英文副标题、日期、来源、编号 | 留下对当前观众真正有用的部分，其余移到备注 |

## 先形成一个可见的概念

艺术方向必须能画出来。可用“以价格差作为负空间，巨型结果数字与细线证据形成对比”“以一条连续的流程串起筛选与落地”“以同尺度对照直接显现差异”等具体描述。它们是思考示例，不是固定模板。

没有用户参考且旧稿被否定时，画两种构图比较：例如一稿由排版与数据主导，另一稿由明确的空间/结构关系主导。不要用同一组卡片、同一网格仅换两种颜色当探索。先看真实渲染再选择；不必让用户代做艺术指导。

有参考时提取其比例、密度、排版性格、留白和视觉语言，不照抄内容或把截图当整页。需要查找新设计参考时优先实际作品/品牌设计规范，不用模板广告代替判断。

## 精细设计的几个抓手

**视觉层级。** 主结果或主视觉需要明显的尺度与对比优势，次要信息要能退后。避免每个模块同大小、同字重、同面积。主标题也可以让位于数据；不要同时制造两个抢眼焦点。

**网格与光学对齐。** 先设少量对齐轴，再按画面实际重心微调。文字左边缘、数字基线、图形边界与说明应有关系。不要只凭边框数学居中；标点、百分号、箭头和圆形往往需要光学修正。

**排版。** 根据语义断行，避开孤字/孤单位；数字与单位保持清楚的比例与距离。中文、拉丁和数字的字体性格需协调。使用真实可用的字体，留出改字空间；不要靠压缩字符或缩小字号挤内容。大字必须承担叙事角色，不能只是放大标题。

**留白。** 留白应让主视觉完整、关系清楚、读者有停顿。它是构图的一部分，不能用来填补没有内容的页面。先压缩语言，再给必要内容适当空间。

**色彩。** 以明度对比建立层级，再用少量颜色表达含义。颜色主次比颜色数量更重要；不自动采用商务绿、蓝白或黑金。深浅背景变化必须由叙事和构图支撑。

**图形。** 图形应传达差异、方向、数量、尺度或结构。优先具体且可读的视觉关系，不堆通用图标、装饰线、胶囊标签和仪表盘卡片。数据面积/长度/位置必须忠于数值；可编辑并不意味着要增加更多对象。

**整体构图。** 同一页的标题、数据、图形和留白应形成完整画面。不要拼成“上面标题、中间几个模块、下面说明”的惯性结构。如果所有页面去掉文字后轮廓相同，应审视是否内容真的需要这种重复；也不要为了变化而强制轮换。

## 作品验收：看到成品再作判断

先在缩略图看主焦点和完整构图，再在实际尺寸看文字和细节。核心信息在手机缩略图仍应能被辨认；这不意味着所有小字都必须缩略可读。

- 遮住标题，主视觉是否仍能说出这页的核心关系？如果完全失效，图形可能只在装饰。
- 删除一个元素/一段字/一页，必要意思是否仍完整？若完整且更清楚，就删。
- 最先看到的是否正是最重要的信息？第二眼能否找到依据？是否有竞争焦点或大量碎片？
- 相同信息的两种构图，哪一种更清楚、更有辨识度、细节更精确？用具体观察作选择，不打虚构分数。
- 对照实际 PPT 与 SVG，确认没有缺字、位移、误导比例或编辑困难。技术问题单独修，不能用技术通过替代前面的判断。

检查记录只需短段落，说明取舍和仍有的局限，不新建一套冗长审批表。用户说“普通、一般、不高级”时，优先重新组织内容和主视觉，不继续在原版式上堆装饰。
