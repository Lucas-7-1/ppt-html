# 整体审美方法：从内容关系到视觉秩序

用于新稿艺术指导、整体审美优化和已认可作品的精修。用这套方法决定设计，不要求用户填写表单，也不向每份交付附加方法论报告。

把美观理解为几种关系共同成立：内容与气质相称，视觉主次清楚，元素之间有秩序，整套有节奏，细节经得起观看。可读和准确是底线；辨识度、情绪与审美取舍仍需看实际作品判断。不要把这些关系换算成虚构评分或通用配额。

## 1. 确定艺术意图：让形式适合这次沟通

先理解观看方式和观众心境：现场讲述、独立阅读与手机速览的密度和节奏不同；审议决策、建立向往、解释机制和教学操作，需要不同的视觉气质。从实际材料找到最值得被看见的关系或意象，再决定表达方式。

把“高级、好看、专业”转成可执行的选择。用一两句话说明：什么是画面的主导概念，为什么适合内容，哪些形式手段建立这种气质。可以选择克制或鲜明、安静或有冲击、几何或有机；不必逐轴打分，也不把某种风格当成更高级。

需要参考时，优先看用户认可的作品、品牌规范或真实设计作品。提取比例、排版、留白、色彩职责和构图机制，说明借鉴的是哪种关系。只在缺少判断依据时检索，不强制每次做情绪板或研究；文字广告和模板分类不能代替看作品。

用户认可某份作品后，保留它已成立的表达意图。记录可观察的特征及适用范围；“这份稿子好看”不自动代表用户永久偏爱某个色号、字体或造型。用户明确要求将某个效果固化为默认时，以 [已认可视觉基准](approved-style.md) 执行；只有新的明确指令才改变默认。

## 2. 把内容关系变成构图：先成立骨架

识别这一页真正需要呈现的关系，再选视觉机制：比较需要可比较的尺度与位置；层级需要清楚的归属；流程需要准确的方向；权衡需要把代价放在一起；情境可以由具体对象或概念空间承担。把它们当推理起点，允许混合与变形，避免机械地把“出现三个概念”翻译成“三张卡片”。

先安排主导元素、辅助证据和负空间。主导元素可以是数字、图形关系、排版、图像或具体工作对象。让大小、位置、明暗与周围空隙共同建立主次；不要默认标题永远最大。需要平等比较的对象可以同等突出，重要的是阅读关系清楚。

用邻近表达分组，用共同轴线建立秩序，用比例和空隙表达重要性。先看整体轮廓和视觉重量，再看单个模块。对称适合稳定和对照，不对称适合方向感与张力，按任务选择。

在可理解的秩序中安排有意的变化：尺度反差、裁切、偏移、疏密或色彩差异，都可以让画面有记忆点。变化应强化表达；避免所有对象同时放大、加粗、上色。概念图形可以建立情绪和空间，不必逐笔解释事实，但不得伪装成数据或真实结构。

方向不清时，用相同事实比较不同构图机制；候选都弱就继续调整。先用灰度或简化形状观察骨架，颜色本身承担意义的内容则保留必要标记。灰度只是诊断方法，不是所有页面的强制风格。

## 3. 建立视觉语法：让所有选择属于同一作品

形成少量项目内的共同约定，并在原型中验证：

| 要素 | 需要决定的关系 | 观察依据 |
| --- | --- | --- |
| 字体与排版 | 字体气质、层级、行长、行距、中文断行和数字单位的比例 | 第一眼与后续阅读是否顺畅，是否出现过多同等强度的文字 |
| 空间 | 页边距、对齐轴、组内与组间距离、重心和负空间 | 元素是否彼此有联系，是否拥挤或松散，留白是否形成清楚的焦点 |
| 色彩 | 背景、正文、强调与分类各自的职责，明度与面积的强弱 | 强调是否落在正确内容上，浅色是否可读，同色是否产生歧义 |
| 图形 | 线宽、端点、曲率、圆角、边界和空间深度 | 相同角色是否一致，不同图形是否仍像同一作品 |

这些约定允许围绕主导概念作有意变化。统一的是设计逻辑，不是每页外形。将字体、颜色、间距和真正重复的语义对象写成可复用原语；不要用一个标题/正文/页脚模板承包所有页面。

让强调有机会被看见：相邻的文字、图形与色块需要有强弱差。不要把“少颜色、少文字、大留白、无阴影”当成通用审美答案；密集的信息、丰富色彩和空间效果也可以成立，前提是有清楚的组织和与内容相称的气质。

## 4. 编排整套：用叙事形成节奏

让观众每翻一页都理解新的关系。开场建立兴趣或主张，展开提供证据，关键节点形成停顿或转折，收束留下决定或行动；这些是叙事作用，不要求额外增加封面、章节页或结束页。

在缩略图中观察视觉重量、密度、尺度、深浅与主视觉的连续变化。重点页要有足够分量，解释页要给阅读空间，复杂页之后是否需要停顿由真实认知负担决定。避免机械地轮换深浅背景或强迫相邻页变布局。

用持续出现的排版关系、颜色含义或图形特征建立辨识度。一个母题可以变化尺度、位置和用途；不需要在每页重复同一个装饰。比较同类信息时保留相同结构，内容关系改变时允许版式改变。

用开场/关键页和代表性的复杂内页验证艺术方向。只有开场成立时，先解决内页的关系与信息密度，再批量扩展。不要用一张漂亮封面掩盖整套缺乏组织。

## 5. 用实际观看校准：先改影响最大的原因

先对照已认可基准的代表页，再按三个尺度观察，记录具体缺陷和对应改动：

- **整套缩略图**：看气质、节奏、轮廓和重点是否一致；关注是否大面积同形或每页都在争夺注意力。
- **正常观看尺寸**：看阅读顺序、主张与证据距离、分组、对比和观看环境中的可读性。不要要求所有注释在手机缩略图中可读。
- **局部细节**：看中文断行、标点、字重、数字基线、光学对齐、线条端点、圆角和图形交接。最终以请求载体的实际渲染为准：PPT 看导出的 PPT，HTML 看实际浏览器。

按“意图与内容组织 → 构图与主次 → 整套节奏 → 排版及图形细节”排查。前一层的问题存在时，先处理高影响原因；小修饰无法补救错误的骨架。已认可的作品则从最明显的残留缺陷开始，不强制重新探索。

需要判断时做可逆的对照：去掉一个抢眼元素，看主次是否更清楚；改变间距，看分组是否更直接；减弱背景，看主体是否更完整；比较两种尺度，看气质是否更贴切。一次比较聚焦一个明确疑问，不把所有变量同时改掉。

准确性、可读性与编辑性必须保留。两种方案都成立时，按艺术意图与用户偏好选择；局部精修的改善不明显，就保留已有方案。主要缺陷已解决后停止，避免为了显示工作量继续改变。

## 把经验留成判断，而非固定外观

案例应记录“观看情境—构图机制—取舍—实际结果”，保留可查看的作品。迁移主次、关系、节奏和校准方法；配色、造型与密度要回到新内容重新判断。

交付时简洁解释影响最大的设计决定，并展示真实成品。用户只问方法论时，聚焦上述决策逻辑，不擅自转成几张具体页面的修修补补，也不以原则条数、自封等级或技术指标证明美感。
